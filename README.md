## How we work

```
Discover  →  Design  →  Build  →  Launch  →  Support
```

**1. Discover** — We map the problem, the users, and the numbers that matter before writing code.
**2. Design** — Wireframes and a design system you sign off on, not a surprise at the end.
**3. Build** — Weekly, reviewable progress on a real staging URL.
**4. Launch** — Performance, SEO, and analytics checked before we hand over the keys.
**5. Support** — We stay on for maintenance, and we document everything.
